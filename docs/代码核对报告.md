### 其中最容易坑到玩家的四条（已单独复核过代码原文）

1. **修复残骸祭坛是「下降」一个大境界（损失九阶）**，是代价不是奖励。
   `lj_remains_altar.lua:21-26` 注释原文「修复完成时让建造者掉落一个大境界（九阶）」→ `lj_realm_value.lua:275-290` `DropOneMajor()`。设计文档的「掉落」是字面意思。
2. **入魔生命加成不是固定百分比**，见第二节第 5 条与报告 A 的计算表。
3. **焚灼 / 冰蚀不是平砍 +15 / +30**，而是各挂一个 8 秒减益、每 0.5 秒跳 16 点伤害。
   `lj_debuffs.lua:663-675`（焚灼，火焰伤害）、`:678-695`（冰蚀）。
4. **「灵技」系统在 mod 源码里不存在**——全库没有相关预制体与字符串，虚空戒与灵煊尘火的「解锁灵技」暂按未实装处理。

## 二、结论摘要（最要紧的 8 条）

1. **虚空戒的真实 id 是 `lj_void_ring`**，不是文档写的 `lj_magic_ring`。
2. **镇魔枢核的产物 id 是小写 `lj_subdue_demons_nucleus`**；文档那个大写 `lj_Subdue_demons_nucleus` 只保留在**配方名**里（代码注释明说"保留旧配方名称，产物和图集使用现有的小写名称"）。
3. **玄灵培育池 `lj_reiki_cultivatepool` 根本没实装**——代码里搜不到，`prefab_groups.lua` 也没有登记，`language_zh.lua` 里没有任何相关中文名。只有一句注释：「妖树培育用途尚未接入」。
4. **「魔兽森林」在代码里的实际载体是「蝴蝶岛」**（`lj_butterfly_island` / `lj_butterfly_winter` / `lj_butterfly_ice` / `lj_butterfly_penguin` / `lj_butterfly_rookery` / `lj_butterfly_frozen_pond`）。
5. **入魔血量不是简单 +70%/+120%/+180%**。代码用的是一个**递减公式**，文档给的例子（2000→3400 等）与实际算出来的数值**差很多**。详见 `差异核对-A-入魔.md`。
6. **阵法最少要 8 面阵旗，不是 4 面**；阵旗间距是"最少 3 地皮、最远 6 地皮"；12×12 是**所有阵法**的外接矩形上限，不是四季调和阵专属。
7. **原版图标缺口全部关闭**——53 个配方材料图标在 `images/` 里**一个不缺**，之前判定的"图标缺失"全是我猜错了文件名。
8. **两处 id 定案**：`lj_swollen_scroll`（我按文档笔误修正的，代码确认正确 ✓）；`lj_soul_devouring_snake`（文档正确，动画包名 `lj_three_headed_snake` 只是模型名）。

## 八、其他代码事实（文档未提）

1. **科技站分级**：基础修炼设施（丹炉、阵旗、悟道淬体台、灵虚光盏、灵玉台、荒界纳物箱、聚气淬具匣、魔核、魔晶、淬铁灵剑）用 **二本科技（`TECH.SCIENCE_TWO`）并永久解锁**；高阶装备与阵眼用 **`TECH.ETHEREAL_REALM_ONE`，必须靠近已修复的残骸祭坛（`nounlock = true`，不会永久解锁）**。
2. **阅读线索日志有境界门槛**：`required_realm_major = 5`（即 **入微** 及以上才能读日志），但**世界线索从开局就会投放**。
3. **魂幡判定半径** `SOUL_BANNER_RADIUS = 12`（3 地皮），检索间隔 `0.3` 秒。
4. **三大魔兽入魔不追加掉落**：`lj_moon_lion` / `lj_chiyan_scorpion_dragon` / `lj_soul_devouring_snake` 自带完整掉落，入魔时不再额外追加魔材与异火。
5. **经验奖励按"入魔前最大生命"计算**，避免血量强化同时放大经验收益；`kill_exp_radius = 60` = 15 地皮 ✓（与文档"15 个地皮"一致）。
6. **mod 官方制作栏位**（`recipes.lua` 的 filter）：`REFINE 精炼` / `STRUCTURES 建筑` / `CONTAINERS 储存` / `LIGHT 光源` / `WEAPONS 武器` / `ARMOUR 盔甲` / `TOOLS 工具` / `MAGIC 魔法`。
7. **mod 自己的文件分类**（`config/prefab_groups.lua`，可作 wiki 分卷参考）：材料 / 武器护具与法宝 / 丹药异火与特殊炼制物 / 灵植及其采集产物 / 建筑与工作台 / 阵旗枢纽与阵眼 / 普通生物与巢穴 / 大型魔兽与刷新点 / 临时效果 / 线索日志与任务道具 / 世界锚点与冬季布景。
8. **灵虚葫与魂幡在 mod 自己的分类里属于「武器、护具与法宝」**，不属于丹药——当前 wiki 把它们放在「丹药与炼制」卷目（依文档），可考虑移到「法宝与工具」。
