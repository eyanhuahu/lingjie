# 灵界资料站 —— 代码目录说明

**普通维护者不要改这个目录里的任何文件。**

站点结构：

| 文件 | 作用 |
| --- | --- |
| `app.js` | 页面逻辑：卷目、卡片、搜索、详情弹窗、词条跳转、滚动侦测 |
| `js/sheetsContent.js` | 内容加载：读取仓库一级目录的 `data.json` 并归一化；另保留旧的 `content.xlsx` 解析器（当前未使用） |
| `styles.css` | 样式 |

内容源是仓库一级目录的 `data.json`（不再使用 `content.xlsx`）。

维护说明见仓库一级目录的 `注释.md`。
